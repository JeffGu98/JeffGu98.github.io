## 问题

where a = null 筛不出空值。where a != 1 也漏掉了空值。

## 结论

SQL 用三值逻辑。比较的结果可以是真、假或未知。NULL 参与的等号比较结果是未知，不会通过 where。要找空值用 IS NULL，要找非空用 IS NOT NULL。a != 1 对 NULL 行也不是真，所以这些行不会出现。聚合里 COUNT(列) 不计 NULL，COUNT(*) 计行。

## 依据

在库里插一行该列为 NULL，分别跑 = NULL、IS NULL 和 != 1。只有 IS NULL 能把它选出来。唯一约束对 NULL 的处理在不同数据库里不一样，不能假设两个 NULL 会互相冲突。

## 还不确定

有的数据库提供 NULLS FIRST 这类排序控制。默认把 NULL 排在哪一头，要以你用的库为准。
